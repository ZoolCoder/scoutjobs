Pick one way to fill this page:

  1. Gmail API (recommended). Create a Desktop OAuth client in your own Google Cloud project. Put gmail_client_id and gmail_client_secret in config.yaml, then run scoutjobs gmail connect. ScoutJobs reads your inbox and creates drafts. It never sends.
  2. IMAP. Set imap_host: imap.gmail.com:993 and SCOUTJOBS_IMAP_PASSWORD (a Google app password), then run scoutjobs email sync.
  3. Agent connector. In Claude with the Gmail connector, say “check my inbox”. The inbox-triage skill records matched threads with scoutjobs email log.
