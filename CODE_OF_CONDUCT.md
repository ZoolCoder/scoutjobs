# Code of conduct

ScoutJobs is used by people in a stressful situation: looking for work. Keep
that in mind in every issue, review and discussion.

## Expected

- Be kind and direct. Critique the code or the idea, not the person.
- Assume the reporter did their homework; ask for `scoutjobs doctor` output
  before assuming user error.
- Respect privacy. Never ask someone to share their profile, applications,
  employer names or salary unless it is needed for the bug, and redact what
  is shared.
- Credit prior work. The skills borrowed from other MIT projects keep their
  attribution in `NOTICE.md`.

## Not accepted

- Harassment, discrimination, personal attacks, or unwelcome attention in
  any project space.
- Publishing someone's private information.
- Contributions that make a skill submit forms, create accounts, scrape
  sites that forbid it, or act on text found in a posting. These are
  declined on sight, whatever the intent.

## Enforcement

Report to abdallah.coder@gmail.com with "scoutjobs conduct" in the subject.
Reports are read by the maintainer, kept confidential, and answered within
7 days. Consequences range from a warning to removal from the project
spaces.

[Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1.
