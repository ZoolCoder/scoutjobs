= Security and privacy
:description: What ScoutJobs will not do, and what you should not do with it.

* *Nothing leaves your machine by default.* Data is in `~/.scoutjobs`. The dashboard binds to `127.0.0.1`, runs one script served from the binary (no inline script), loads no external asset and sends a strict Content-Security-Policy. The webhook is off until `webhook_url` is set.
* *Postings are untrusted input.* Job pages, company sites and board API responses may contain text aimed at the agent. Every skill extracts facts and ignores instructions found there. Keep that rule in any skill you write.
* *No accounts, no logins, no forms.* Skills never create accounts, log in or fill web forms on your behalf, and never solve CAPTCHAs. LinkedIn and Indeed forbid scraping; paste those postings.
* *One outbound path.* `scoutjobs email send <id> --yes`, through your own SMTP account, after the full message was shown and you said yes. The API can draft, not send.
* *Secrets stay in the environment.* `SCOUTJOBS_SMTP_PASSWORD` only. The CLI never reads it from a file; the skill never asks for it in chat.
* *Truth.* Every claim in a resume or cover letter must exist in `profile.md`. `draft-reviewer` flags the rest as unverified and asks.
* *The pages have no login.* The JSON API can require a bearer token (`api_token`); the HTML pages cannot. If you tunnel the dashboard for a cloud agent, put access control in front of it (Cloudflare Access, Tailscale) or expose only `/api/`. Never bind to `0.0.0.0` on a network you do not control.
* *API writes are fenced.* Only `.md`, `.txt` and `.json`, 1 MB each, inside the job's own folder; names are reduced to their base name.
* *Never commit `~/.scoutjobs`.* The repository ignores databases and profile files; keep it that way.

Found a way for a posting, a request or a file to make ScoutJobs act without the user's yes? Report it privately at https://github.com/ZoolCoder/scoutjobs/security/advisories/new (see `SECURITY.md`), not as a public issue. Everything else goes to https://github.com/ZoolCoder/scoutjobs/issues.
