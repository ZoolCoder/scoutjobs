= ScoutJobs
:description: Your job search, on your machine: agent skills, a local dashboard and a CLI.

[.hero]
--
ScoutJobs is a job-search operating system for the person looking for a job, driven by the AI coding agent you already use.

Skills find postings, score them against your profile, check and tailor your CV, write the cover letter, send the application from your own mailbox, prepare you for interviews and learn from every decision you make. A single Go binary keeps the state in `~/.scoutjobs`: SQLite, Markdown files, a dashboard on localhost. No accounts, no keys, no telemetry.

Three layers, one contract:

[.cards]
* *Skills* +
Markdown instructions in the Agent Skills standard. Claude Code gets them as a plugin with slash commands and subagents; Codex, Cursor, Gemini CLI and Copilot read the same `SKILL.md` files. Skills never touch the database. They call the CLI.
* *CLI* +
`scoutjobs` owns the data: jobs, events, decisions, preferences, interviews, sessions, learning items, CV checks, e-mail drafts. Every read takes `--json`, so an agent and a human see the same thing.
* *Dashboard and API* +
`scoutjobs serve` renders the same data as pages with no JavaScript, and exposes it as a JSON API with a bearer token for n8n, cron and agents that run somewhere else.
