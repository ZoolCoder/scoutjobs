# Getting help

ScoutJobs is maintained in spare time by one person. Pick the channel that
fits so questions get an answer and bugs get fixed.

| You want to | Go to |
|---|---|
| Learn how something works | The [user manual](https://zoolcoder.github.io/scoutjobs/), starting with [troubleshooting](https://zoolcoder.github.io/scoutjobs/scoutjobs/troubleshooting.html) |
| Report a bug or a skill that misbehaved | [New issue](https://github.com/ZoolCoder/scoutjobs/issues/new/choose), with `scoutjobs doctor` output |
| Ask for a board, a skill or a feature | [Feature request](https://github.com/ZoolCoder/scoutjobs/issues/new/choose) |
| Ask a question or share how you use it | [GitHub Discussions](https://github.com/ZoolCoder/scoutjobs/discussions) |
| Report a security problem | [SECURITY.md](SECURITY.md), never a public issue |
| Contribute code, docs or a skill | [CONTRIBUTING.md](CONTRIBUTING.md) |

## Before you ask

1. Run `scoutjobs doctor`. It names the broken step and how to fix it.
2. Run `scoutjobs version` and check the [releases page](https://github.com/ZoolCoder/scoutjobs/releases) for a newer one.
3. Search the existing issues.

## What to include

- `scoutjobs doctor` and `scoutjobs version` output.
- Platform: macOS, Linux or Windows, and the agent (Claude Code, Codex, Cursor, Gemini CLI, Copilot, other).
- For a skill problem: the prompt you gave, what the agent replied, and what you expected.

Never paste `profile.md`, the database, application folders or a real
employer's posting. Redact names and salaries.

## Response time

Issues are read within a week. There is no paid support and no SLA; fixes
land in the next release.
