Once, about 3 minutes: a Desktop OAuth client in your own Google Cloud project, so your mail goes to no one else.

  1. Create a project, any name.
  2. Enable the Gmail API in it.
  3. Set up the consent screen: app name ScoutJobs, audience External, your e-mail. Then Audience › Publish app; in Testing mode Google drops the connection every 7 days.
  4. Create an OAuth client of type Desktop app, then Download JSON and add it here.

Google warns that it has not verified the app: it is yours, so choose Advanced › Go to ScoutJobs. In a terminal, scoutjobs gmail setup does the same and picks the file up from Downloads. Saved to {{.Home}}/gmail-client.json (0600).
